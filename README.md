# Lava Jato Rafael

Site demonstrativo para lavagem de carros e motos, com agendamento, conta de
cliente, histórico de serviços e programa de fidelidade.

## Estrutura

- `index.html`: página do site, com estilos e funcionalidades em JavaScript.

## Como executar

Abra `index.html` em um navegador moderno. Não é necessário instalar
dependências nem iniciar um servidor. O site usa `localStorage` para manter
contas, agendamentos e regras do Clube neste navegador.

## Observação

Esta é uma demonstração front-end: pagamentos, QR Code Pix, horários ocupados,
confirmações e área da equipe não se conectam a serviços externos ou a um
servidor. Os dados ficam apenas no navegador utilizado.
